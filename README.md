# Система для ветлечебницы (VetClinic App)

Информационная система для автоматизации рабочих мест сотрудников ветеринарной лечебницы и проведения многофакторного вычислительного эксперимента по определению безопасных дозировок препаратов. Лабораторная работа выполнена на языке программирования Python.

## 🚀 Возможности системы
* **Авторизация персонала:** Защищенный вход в систему с проверкой учетных данных в базе SQLite.
* **Учет пациентов:** Форма добавления, регистрации и вывода списка животных.
* **Вычислительный эксперимент:** Математическое моделирование и расчет дозировок седативных средств на основе веса, вида и индивидуальных физиологических рисков пациента.

## 🛠 Технологический стек
* **Язык программирования:** Python 3.x
* **Интерфейс (GUI):** Tkinter (стандартная графическая библиотека)
* **База данных:** SQLite3 (реляционная СУБД)

## 📁 Структура версий в репозитории
* `vet_app_v1.py` — Базовая консольная версия программы (CLI).
* `vet_app_v2.py` — Финальная улучшенная версия с графическим интерфейсом (GUI), формами добавления записей и продвинутым алгоритмом расчета рисков.
